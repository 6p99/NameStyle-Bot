# NameStyle-Bot

بوت ديسكورد (Python / discord.py) بينشر لوحة تحكم بروم محددة باستخدام Components V2 (بدون Embed). من خلاله فيك تحط توكن أي بوت وآيدي سيرفره، وتختار له لون/شكل خط/تأثير من قوائم جاهزة، والبوت بيبعث طلب PATCH لـ Discord API عشان يطبق الستايل (`display_name_font_id`, `display_name_effect_id`, `display_name_colors`).

## المتطلبات

- Python 3.10+
- `discord.py` نسخة **2.6 أو أحدث** (فيها دعم Components V2 / `LayoutView`) — موجودة أصلاً بـ `requirements.txt`
- بوت مسجل على [Discord Developer Portal](https://discord.com/developers/applications) مفعّل فيه **Message Content Intent**

## التركيب

```bash
git clone https://github.com/6p99/NameStyle-Bot.git
cd NameStyle-Bot
pip install -r requirements.txt
```

## الإعداد

انسخ `.env.example` لملف `.env` واملأه:

```bash
cp .env.example .env
```

```
RUNNER_TOKEN=توكن_البوت_يلي_رح_ينشر_اللوحة
CHANNEL_ID=آيدي_الروم_يلي_بدك_اللوحة_تظهر_فيها
PREFIX=!
```

- **RUNNER_TOKEN**: توكن البوت اللي بيشغل السكربت وينشر اللوحة بالروم. لازم يكون هذا البوت مدعو عالسيرفر وعنده صلاحية إرسال رسائل ومكونات تفاعلية بالروم المحددة.
- **CHANNEL_ID**: آيدي الروم. فعّل Developer Mode بإعدادات ديسكورد، بعدين كليك يمين عالروم → Copy Channel ID.

`.env` غير مرفوع للريبو أصلاً (موجود بـ `.gitignore`) — لا ترفعه يدوياً ولا تشارك القيم يلي فيه.

## التشغيل

```bash
python bot.py
```

عند نجاح تسجيل الدخول رح تشوف بالطرفية:
```
✅ سجل الدخول: <اسم البوت> (<آيدي البوت>)
```
وبعدها البوت بينشر اللوحة تلقائياً بالروم المحددة بـ CHANNEL_ID. إذا انحذفت الرسالة، رجّعها بأمر:
```
!panel
```
(أو أي بادئة حطيتها بـ PREFIX بدل `!`)

## طريقة الاستخدام

1. دوس زر **🎨 ابدأ**.
2. بيفتح فورم فيه حقلين: توكن البوت المستهدف (اللي بدك تغيّر ستايل اسمه)، وآيدي السيرفر اللي هذا البوت عضو فيه.
3. بعد الإرسال بتظهرلك (رد خاص/ephemeral) ثلاث قوائم اختيار: اللون، شكل الخط، التأثير — كلها معبّية بقيمة افتراضية، فحتى لو ما لمست شي فيك تدوس **✅ طبّق الستايل** على طول.
4. البوت بيبعث الطلب لـ Discord، وبيرد عليك بنجاح أو بكود الخطأ لو صار في مشكلة.

## ملاحظات مهمة

- **الفيلدز غير موثقة رسمياً من Discord** (`display_name_font_id`, `display_name_effect_id`, `display_name_colors`) — يعني ممكن تتغير أو توقف تشتغل من غير سابق إنذار، وأرقام الخط/التأثير ما إلها معنى معروف، جرّب أكثر من رقم لحد ما تلاقي الشكل يعجبك.
- **التوكن يلي بتحطه بالفورم ما بينحفظ بأي مكان** — بيستخدم لحظياً بس عشان يبعث طلب PATCH وبعدها بينرمى من الذاكرة.
- أي حدا بيشوف الروم فيها اللوحة يقدر يدوس **ابدأ** ويحط أي توكن، فخلي الروم مقفلة على الناس يلي بس بتوثق فيهم.
- لا تختبر توكنات بوتات إنتاجية/مهمة — جرب على بوت وسيرفر تجريبي أول.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `ModuleNotFoundError` | نفّذ `pip install -r requirements.txt` مرة ثانية |
| `SyntaxError` بأول تشغيل | تأكد إنك ما حطيت التوكن جوا `bot.py` — لازم يكون بس جوا `.env` |
| `Invalid Form Body` / `Invalid emoji` | حدّث `bot.py` لآخر نسخة، هاي كانت مشكلة انصلحت |
| فشل الـ PATCH بـ status 4xx | تأكد إن البوت المستهدف فعلاً عضو بالسيرفر يلي حطيت آيديه، وإن التوكن صحيح |
| اللوحة ما ظهرت بالروم | تأكد إن RUNNER_TOKEN صح وإن البوت عنده صلاحية إرسال رسائل بالروم |
