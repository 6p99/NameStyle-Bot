# NameStyle-Bot

شرح تفصيلي بالعربي لكيفية تشغيل واستخدام المشروع NameStyle-Bot، متضمّن تعليمات عملية، إعدادات بيئية، ونصائح أمان.

## نبذة سريعة
NameStyle-Bot هو سكربت Python (بوت ديسكورد) يرسل رسالة تفاعلية داخل قناة محددة تتيح اختيار شكل اسم البوت (لون، خط، تأثير) ثم يعالج طلب PATCH إلى Discord API لتطبيق إعدادات عرض الاسم لحساب بوت آخر داخل نفس السيرفر.

> ملاحظة أمان مهمة: السكربت يطلب من المستخدم إدخال توكن بوت آخر داخل واجهة تفاعلية (Modal). توكن البوت هو بيانات حسّاسة — لا تشاركها مع أي أحد، ولا ترفعها إلى المستودع. تأكد أنك تفهم المخاطر قبل اختبار هذه الميزة.

## المتطلبات
- Python 3.8+
- Git
- الحزم في `requirements.txt` (discord.py, aiohttp, python-dotenv)

## تركيب المشروع
1. استنساخ المشروع:
```bash
git clone https://github.com/6p99/NameStyle-Bot.git
cd NameStyle-Bot
```

2. أنصح ببيئة افتراضية:
```bash
python -m venv .venv
# mac / linux
source .venv/bin/activate
# windows
.venv\Scripts\activate
```

3. تثبيت التبعيات:
```bash
pip install -r requirements.txt
```

## إعداد المتغيّرات البيئية (.env)
أنشئ ملف `.env` في جذر المشروع واملأ القيم التالية:

```
# توكن البوت الذي يشغّل الواجهة (Runner bot)
RUNNER_TOKEN=توكن_بوت_التشغيل

# آيدي القناة التي يُرسل لها البوت واجهة التكوين
CHANNEL_ID=رقم_القناة

# بادئة الأوامر (اختياري)
PREFIX=!
```

تفسير المتغيّرات:
- RUNNER_TOKEN: توكن البوت الذي سيشغّل هذا السكربت (البوت الذي يرسل لوحة الواجهة إلى القناة). هذا البوت يجب أن يكون مدعوًا للسيرفر وله صلاحية إرسال رسائل ومكوّنات تفاعلية.
- CHANNEL_ID: رقم القناة (Channel ID) حيث سيُرسَل عرض الواجهة. للحصول على Channel ID فعّل Developer Mode في Discord ثم كليك يمين على القناة → Copy ID.

ملاحظة أمان: لا ترفع ملف `.env` إلى الريبو. أضف `.env` إلى `.gitignore` لو لم يكن موجودًا.

## تشغيل البوت
بعد إكمال الخطوات أعلاه:

```bash
python bot.py
```

سترى رسالة في اللوحة الطرفية تحتوي على:
```
✅ سجل الدخول: <bot_user> (<bot_id>)
```
ثم سيُرسل البوت رسالة تفاعلية إلى القناة المحددة.

## كيفية الاستخدام داخل Discord
1. افتح القناة المحددة في السيرفر؛ البوت سيرسل رسالة واجهة تلقائيًا عند بدء التشغيل. يمكنك أيضًا تشغيل الأمر `!panel` (أو البادئة التي اخترتها) داخل السيرفر ليعرض الواجهة يدويًا.
2. اضغط زر "ابدأ" 🎨 لفتح النموذج (Modal).
3. داخل النموذج ضع:
   - توكن البوت الذي تريد تغيير اسمه/ستايله (ملاحظة: هذه الآلية تطلب توكن بوت آخر). 
   - Guild ID (آيدي السيرفر الذي البوت الآخر موجود فيه).
4. بعد الإرسال ستظهر قائمة للون، شكل الخط، والتأثير — اختَر القيم ثم اضغط "طبّق الستايل".
5. السكربت يستدعي `apply_name_style()` والتي ترسل PATCH إلى Discord API على المسار `/guilds/{guild_id}/members/@me` مع الحقول:
   - display_name_font_id
   - display_name_effect_id
   - display_name_colors

إذا نجح الطلب سترى رسالة تؤكد التطبيق؛ وإن فشل سيعرض كود الحالة وبيانات استجابة الـ API.

## ملاحظات تشغيلية وفنية
- الكود يستخدم `discord.Intents.default()` مع `intents.message_content = True` — فعّل "Message Content Intent" في صفحة تطبيق البوت على Discord Developer Portal إذا لزم الأمر.
- تأكد أن البوت (RUNNER_TOKEN) لديه صلاحية إرسال رسائل ومكوّنات تفاعلية في القناة.
- الـ endpoint المستخدم قد يكون محكومًا بسياسات Discord أو صلاحيات البوت الآخر. إذا رفضت الـ API الطلب، راجع صلاحيات البوت المستهدف وإمكانات API الخاصة بالحساب.
- لا تختبر توكنات على خوادم إنتاجية؛ جرّب على سيرفر تجريبي أولاً.

## استكشاف الأخطاء وإصلاحها
- `ModuleNotFoundError` أو `ImportError`: تأكد من تنشيط البيئة الافتراضية وتثبيت الحزم.
- `nstyle: command not found` — غير مطبق هنا (كان مثال في مستندات سابقة). تجاهل إذا لم تستخدم nstyle.
- استجابة HTTP بخطأ 4xx/5xx: افتح سجل الاستجابة (يُطبع JSON أو نص الاستجابة في الرسالة الظهرية) وتحقق من سبب الرفض: صلاحيات/نطاقات/سياسة.
